## 🔧 Разработка и API TVLINK

Скраперы разработаны для работы с TVLINK и используют API дополнений, включая модуль `utils`, предоставляемый TVLINK.

Официальная документация API дополнений:

- [API дополнений TVLINK — AlexELEC](https://alexelec.run.place/docs/tvlink/docs/addons-api/)

### Добавление скраперов в TVLINK

TVLINK поддерживает механизм добавления источников через интерфейс `Add addon` на странице `Sources`.

Для интеграции дополнений в штатный механизм распространения TVLINK используется репозиторий:

- [TVLINK-ADDONS — официальный репозиторий дополнений](https://github.com/AlexELEC/TVLINK-ADDONS)

Если дополнение с указанным именем отсутствует в репозитории, TVLINK создаёт пустой файл скрапера в каталоге `tvlink/scrapers`.

Скраперы из данного репозитория BarrelGun могут устанавливаться вручную согласно инструкции выше.
