## 🔧 Разработка и API TVLINK

Скраперы разработаны для работы с TVLINK и используют API дополнений, включая модуль `utils`, предоставляемый TVLINK.

### Официальная документация API

- [API дополнений TVLINK — AlexELEC](https://alexelec.run.place/docs/tvlink/docs/addons-api/)

В официальной документации описаны структура дополнений, взаимодействие с TVLINK, функции `Channels()` и `getLink()`, а также работа с модулем `utils`.

### Добавление скраперов в TVLINK

TVLINK поддерживает механизм добавления источников через интерфейс `Add addon` на странице `Sources`.

Для интеграции дополнений в штатный механизм распространения TVLINK используется официальный репозиторий:

- [TVLINK-ADDONS — официальный репозиторий дополнений](https://github.com/AlexELEC/TVLINK-ADDONS)

Если дополнение с указанным именем (без расширения `.py`) отсутствует в официальном репозитории, TVLINK создаёт пустой файл скрапера в каталоге `tvlink/scrapers`.

Скраперы из данного репозитория BarrelGun устанавливаются вручную в каталог скраперов TVLINK согласно инструкции по установке, приведённой выше.
